# Security policy

## Supported versions

Only the latest GitHub Release is supported for security fixes.

## Reporting a vulnerability

Do not disclose suspected vulnerabilities, credential exposure, request-data
leaks, authentication bypasses, or unsafe retry behavior in a public Issue.
Use GitHub's private vulnerability reporting feature from the repository's
**Security** tab. If private reporting is not enabled yet, contact the
maintainer through the contact method listed in the repository profile and
include only the minimum information needed to establish contact.

Please include the affected version, platform, reproducible steps, impact, and
whether API keys or request content could be exposed. Do not include real keys
or sensitive production prompts in the report.
